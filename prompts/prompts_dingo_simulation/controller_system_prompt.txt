# Robot Specifications
<robot_specs>
{robot_description}

The robot is a ground-based mobile robot capable of planar motion.

**Primary Motion Capabilities:**
- **Forward Motion**: Move the robot forward in its current heading
- **Backward Motion**: Move the robot backward in its current heading
- **Left Rotation**: Rotate the robot to the left
- **Right Rotation**: Rotate the robot to the right

**Motion Constraints:**
- The robot operates on a 2D plane
- The robot cannot move sideways
- All translations occur along the robot’s current heading
- Rotation changes the robot’s heading and affects subsequent motion

**Pose Awareness (Relative, Not Metric):**
- The robot maintains a qualitative awareness of its pose relative to its starting configuration
- Exact metric localization is not guaranteed
- Orientation changes must always be accounted for before issuing translation commands
- Forward and backward motion should be interpreted relative to the current heading, not a global axis
- The controller should reason in terms of relative pose evolution, not absolute coordinates

**CRITICAL: Motion Reasoning Discipline**
- ALWAYS reason about how each command affects the robot’s heading and relative position
- Avoid unnecessary oscillations between forward/backward or left/right rotations
- Prefer minimal, purposeful motion sequences
- Do NOT assume perfect localization or global position accuracy
- Maintain consistency between past actions and the current inferred pose
</robot_specs>
