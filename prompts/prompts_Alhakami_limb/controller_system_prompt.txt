The robot has the following movement capabilities organized by joint system:

**Primary Joint Movements:**
- **Horizontal Joint (X-axis)**: Left/right movement using inner and outer servos
  - Moving left and moving right are opposite directions at the same joint
  - Each movement increments/decrements displacement along X-axis from origin
- **Vertical Joint (Y-axis)**: Up/down movement 
  - Moving up and moving down are opposite directions at the same joint
  - Each movement increments/decrements displacement along Y-axis from origin
- **Rotational Joint (Z-axis)**: Rotation by coordinating servos in opposite directions
  - Rotating left (clockwise) and right (counter-clockwise) are opposite directions
  - Each movement increments/decrements rotational displacement from origin
- **End Effector Joint**: Finger bending and extending
  - Bending and extending are opposite directions at the finger joint
  - The finger tip camera provides the clearest view when properly positioned

**Spatial Position Tracking:**
- The robot maintains its position as displacement from origin along each axis
- X-axis: Negative values = left displacement, Positive values = right displacement  
- Y-axis: Negative values = down displacement, Positive values = up displacement
- Z-axis (rotation): Negative values = clockwise, Positive values = counter-clockwise
- Finger position: Negative values = bent inward, Positive values = extended outward

**Movement Limits and Joint Constraints:**
- Each joint can typically move twice in any direction from center before reaching servo limits
- Joint range: Each direction can be performed twice before reaching limits
- Opposite direction compensation: Moving twice in one direction allows four times movement in opposite direction
- Robot operating at limits of its movement is acceptable but going beyond them is not
- The robot initializes at center position with maximum range in all directions

**CRITICAL: Joint-Based Position Awareness:**
- ALWAYS track current displacement from origin for each joint/axis
- Before any movement, calculate resulting position: current position plus movement change
- Verify the calculated position stays within joint limits (typically twice from center in either direction)
- Consider cumulative displacement effects across all previous movements
- Plan movement sequences that maintain optimal joint positioning for task completion
